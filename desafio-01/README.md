# Primeiro Next

Meu primeiro projeto com Next.js, criado para praticar componentes reutilizáveis, rotas com App Router, navegação com `Link` e publicação na Vercel.

## O que é um componente?

> **Antes de entregar:** reescreva este parágrafo com as suas palavras, como solicitado pelo professor.

Um componente é uma parte independente da interface que reúne estrutura e comportamento e pode ser usada em diferentes lugares. Criar o cabeçalho uma única vez evita código repetido: quando for necessário mudar o título ou a navegação, basta editar um arquivo para que todas as páginas recebam a atualização.

## Navegação com Link

O `Link` do Next.js navega entre páginas sem recarregar o documento inteiro, por isso a troca parece mais rápida e não provoca o “piscar” de uma navegação feita com uma tag `<a>` interna.

## Rotas

- `/` — página inicial
- `/sobre` — apresentação e expectativas para o semestre
- `/contato` — página extra de contato

## Componentes

- `Cabecalho` — aparece em todas as páginas e contém a navegação
- `Rodape` — componente extra exibido em todas as páginas

## Como executar

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

Para conferir a versão de produção:

```bash
npm run build
npm start
```
